# 배포 전 확인할 미연결 항목

실제 인터넷 배포 권한/Render 계정이 아직 제공되지 않았으므로 **실제 배포 완료 아님**. 현재 공식 Blueprint 스키마와 요금 페이지는 네트워크 403으로 직접 검증하지 못했다. 공식 GitHub 예시와 일치하는 기본 구조의 `render.yaml`을 제공하며, Render Blueprint 검증 결과를 확인한 뒤 유료 리소스를 생성해야 한다.

- [ ] 저장소 커밋과 Render GitHub 연결(앱 코드는 아직 자동 push하지 않음)
- [ ] 현행 `starter` Web/Worker, `basic-256mb` Postgres 플랜의 제공 여부·요금·리전 확인
- [ ] Blueprint 원격 검증: 특히 plan, postgresMajorVersion, preDeployCommand
- [ ] 소유자 해시·새 세션 키·정확한 APP_ORIGIN 설정
- [ ] HTTPS 로그인/로그아웃, 무인증 API/WS 거절, Origin·CSRF 확인
- [ ] PostgreSQL 마이그레이션, 백업·별도 DB 복원 연습
- [ ] 워커 heartbeat, 공백 알림, 브라우저 종료 중 추적 및 워커 교체 후 주문/보유 유지
- [ ] 합성 모드 추천→부분/전체 체결→분석→사용자 매도→기록
- [ ] 360/390/768/1440px, 200% 확대 및 브라우저 재연결
- [ ] 실제 공급자 이용 권한·API 키·실시간/지연·저장/재배포 범위·출구 IP 확인
- [ ] 실제 주문/취소/체결통보/잔고/외부거래 대사는 별도 구현·샌드박스 검증 필요. 현재 미연결

합성 모드 배포는 실제 시세 연결 완료나 실주문 검증 완료를 의미하지 않는다. 실주문 테스트는 자동 실행하지 않는다.
