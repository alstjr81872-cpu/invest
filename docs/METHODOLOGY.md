# 계산식과 가정

가격/확률을 LLM이 만들지 않는다. 모든 수치는 OHLCV 원자료로 계산한다. `strategies.toml`의 가중치는 **미검증 가설**이며 80점은 상승 확률 80%가 아니다. 목표 달성 확률은 산출하지 않는다.

## 일봉 지표

| 지표 | 공식 / 최소 이력 | 초기/결측 처리 |
|---|---|---|
| MA5/20/60 | 최근 n개 종가 산술평균 / n봉 | 초기 n-1개 null |
| 5/10/20일 수익률 | `(C[t]/C[t-n]-1)*100` / n+1봉 | 결측 자동 채우기 없음 |
| 거래량 비율 | 당일 V / 최근 20개 V 평균(당일 포함) / 20봉 | 초기 null, 0거래량 위험 검사 |
| RSI(14) | 최초 14개 변화의 상승/하락 평균 후 Wilder `(prev*13+current)/14`; `100-100/(1+gain/loss)` / 15봉 | 손실0·상승>0이면100, 양쪽0이면50 |
| ATR(14) | TR=`max(H-L,abs(H-prevC),abs(L-prevC))`, 첫 봉은H-L; 14개 seed 후 Wilder / 14봉 | 초기 13개 null |
| 지지/저항 | 완성 최근20봉 L의 최소 / H의 최대 | 20봉 필요 |
| 상대수익률 | 동일 세션 교집합의 종목 수익률−시장/업종 수익률 | 최신 세션 불일치 또는 이력 부족이면 unknown |

최소 60개의 정상 완성 일봉이 필요하다. OHLC 범위·양의 가격/거래량·유한값·중복/역행 일자를 검사한다. 필수 거래정지·경보·기업행동·사건 위험 상태가 True가 아니면 후보를 통과시키지 않는다. 정상 상태를 가정하는 값은 데모에서만 합성임을 표시한다.

시장 상승/하락은 C/MA20/MA60의 순서, 나머지는 횡보, 데이터 부실은 판단 불가다. 원래 수익률·평균값의 관측과 해당 배열에 따른 해석을 별도로 반환한다.

## 기간별 가격/점수 규칙

2~5일은 관측5일/손절0.8ATR/목표1.6ATR, 6~10일은 관측10일/손절1.1ATR/목표2.2ATR, 11~20일은 관측20일/손절1.5ATR/목표3ATR을 사용한다. 진입은 최신 유효 기준가를 cent 단위로 반올림, 손절은 `max(20일 지지, 진입−손절 ATR배수)`, 목표는 `min(20일 저항, 진입+목표 ATR배수)`다. 매수는 지정가 이내, 추천 생성 15분/주문 대기15분까지만 유효하다. 기준가 대비 0.5%를 넘는 추격은 막는다. 가격/필수 위험/20일 추세 조건이 무효화되면 대기 매수를 거절한다.

추세와 상대강도는 한 묶음(50점)에 제한하고, 거래량/유동성25점, 기간·구조25점으로 나눈다. 추세 묶음은 MA 배열25점 + 상대강도 `clamp(relative*5,0,25)`다. 거래량은 `clamp(volume_ratio*15,0,25)`, 기간구조는 목표>진입이고RSI35~72일 때25점, 아니면5점이다. 뉴스 점수는 없다. 평균 거래대금 $10M 이상, 최소 비용 차감 손익비1.1, 총55점 이상, 목표 순수익률 충족일 때만 최대5개를 통과시킨다. 이 임계값 자체의 유효성은 검증되지 않았다.

## 비용과 수량

현재 수수료·세율의 공식 확인이 없어 **편도 수수료10bp, 슬리피지5bp, 매도세0bp**를 시연 가정으로만 사용한다. `COST_VERSION=demo-assumptions-v1`이다. 실세율/실환전/연간 세금이나 증권사 실비용 모델이 아니며 실주문 게이트를 여는 근거로 사용할 수 없다.

수량은 손실 예산/(진입−손절+왕복 비용·슬리피지), 가용 현금, 사용자 예산, 종목당 한도, 업종50% 한도의 최솟값을 내림한 정수다. 미체결 매수 예약금과 미체결 매도 잔량을 차감한다. 외부 수동 보유는 집중도/보유수에 포함하되 모의 현금에는 더하지 않는다. 해당 종목의 최신 시세가 없으면 신규 매수를 제한한다.

계획 손실과 별도로 진입가 대비15% 갭 하락 스트레스 손실을 보여준다. 이는 최악 손실 한도가 아니다. USD 평가는 체결가 기반 평가액−매수 원가·비용, 즉시 청산 추정은 **매수호가**−매도 비용 기준이다. KRW 평가손익은 `현재USD평가*현재환율−USD원가*진입환율`이다. 실제 환전 손익이 아니며 현재 실제 환율이 미연결이면 표시하지 않는다.

## 가격 백테스트

완성된 신호봉의 이용 가능 시각이 신호 시각보다 늦으면 신호를 생성하지 않는다. 날짜만 있는 뉴스/정정 공시나 과거 available_at 미확인 뉴스는 성과에 넣지 않는다. 현재 뉴스는 일절 사용하지 않는다.

신호 다음 세션 시가가 지정가 이내이며 손절 위에 있을 때만 진입한다. 일봉의 저가 터치만으로 매수 호가의 존재를 가정하지 않는다. 시가+슬리피지가 지정가를 넘으면 미체결이다. 목표·손절 동시 접촉은 손절 우선, 손절 갭은 시가, 목표 갭은 보수적으로 목표가를 사용한다. 보유일은 진입 세션을1일로 세며 만료 세션 종가 청산, 구간 끝은 별도 평가 종료 청산이다. 거래정지 봉에서는 체결하지 않는다. 평가 종료까지 정지가 지속되면 미청산 수량을 결과에 남긴다.

시간순 개발60%/검증20%/최종20%를 나누고 개발/검증 끝에 보유일만큼 간격을 제거한다. 두 expanding walk-forward 구간을 정의하고 규칙 최적화 없이 각 구간을 평가한다. 최종 화면은 최종 평가만 크게 표시한다. 모든 실험은 단일종목+현금이며 상관관계/동시 보유를 반영한 전체 포트폴리오 성과가 아니다. 같은 날짜/자금/25% 비중/비용의 매수·보유와 비교하며 시장 대비 성과는 실제 지수 미확보로 null이다. 목표 선도달 빈도에는 표본수·기간·Wilson95% 구간·만료/손절·가정을 붙이며 미래 확률로 해석하지 않는다.

합성 이력은 엔진 검사용이다. 실제 장기 데이터·상장폐지·시점별 구성종목이 없으므로 **전략 검증 미완료**다. split의 가격×수량 보존 primitive는 테스트하지만 fractional cash-in-lieu는 검증된 피드가 필요하다. 실데이터 기업행동 계수가1이 아닌 백테스트는 조정/원주가 전환을 PIT로 검증하기 전 거절한다. 실계좌 기업행동 자동 반영은 지원하지 않는다.
