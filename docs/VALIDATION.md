## 핵심 테스트가 확인한 것

- MA/RSI/ATR/수익률 기준값과 초기 null, 결측·가격조정 범위 오류, 미래 봉을 바꿔도 과거 지표 불변.
- 세션 교집합 상대수익률, 단기/중기/장기 규칙 구분, 1거래일 이내 미지원, 과도한 목표에서 후보0개.
- NYSE 정규장/시간외, 미국 서머타임, 휴장과 조기폐장, 휴장일을 넘는 보유 만료.
- 수수료·현금·손실 예산·비중·외부 보유 집중도, USD 평가/매수호가 청산 추정/KRW 환율 기여 분리.
- 지연/오래된/연결 끊김/거래정지 unknown, 최근 일봉 부족, 역순·중복 이벤트와 재수신의 비역행.
- 공급자 GET 재시도/캐시·토큰 재사용·오류, 쓰기 재시도 금지, KIS/SEC 모의 계약, 실데이터 실패의 합성 대체 금지.
- 뉴스 별칭·회사명 매칭과 전재 중복, 제목만 분석 표시, 과거 available_at/날짜만 있는 기록의 다음 세션 사용, 잘못된 시각 제외.
- 거래소별 동일 티커 구분 및 영구 ID를 유지한 티커 변경, split의 가격×수량 보존과 미확보 소수 수량 처리 거절.
- 주문 UUID 중복, 같은 키의 변경 요청 거절, 클릭 시 무체결, 부분/전체 체결, 가중평균가, 체결 고유키 중복 제거.
- 취소 후 늦은 이벤트, 미확정 타임아웃의 재전송 금지, 새 클라이언트·프로세스 재시작 후 복원, expired lease 복구·동시 작업 선점.
- 투자 시 가격 허용범위·최신성·설정·보유수·위험 상태 재검사와 진입 대기 중 위험/추세 무효화.
- 보유 만료·첫 목표/손절 보존, 뉴스/분봉 미분석 표시, 포지션 버전과 가격 변화 뒤 늦은 분석의 stale 표시, 분석의 무주문성.
- 백테스트의 다음 거래일 진입·비용·보유 만료·손절 갭·같은 봉 손절 우선·정지 시 미체결·시간 분리·PIT 제외.
- 무인증 HTTP/WS 거절, 정확한 Origin/CSRF, Secure/HttpOnly/SameSite, 로그아웃 폐기·세션 만료·로그인 제한·비밀번호 오류 응답 비노출.
- 미검증 실주문은 서버 플래그를 켜도 실행되지 않음. 모의 DB를 live-data 모드로 바꿔 섞으려 하면 시작 실패.

## 실제 브라우저 인수 결과

로그인 → 새 후보 분석 → Plotly 캔들/MA/거래량/RSI 렌더링 → 모의 주문 → 체결/가격 변화 → 분석 근거 변화 → 합성 과거 실험 → 네트워크 단절/재연결 → 사용자 전량 매도 → 기록 저장을 확인했습니다. 추가 360px 시나리오에서 주문 입력·보유·분석·매도를 다시 수행했습니다.

360/390/768/1440px에서 추천/설정의 페이지 전체 가로 넘침이 없음을 검사했습니다. 720px 뷰포트(1440px 200% 확대에 해당하는 CSS 폭)와 추가 200% 글꼴 확대도 검사했습니다. 이는 실제 Chrome 메뉴의 확대 버튼을 자동 제어했다는 뜻은 아닙니다. 핵심 숫자 줄바꿈을 개선했고 작은 글씨 대신 최소14px 라벨을 사용합니다. Primary 버튼은 #3182F6 대신 #2873DF로 조정하여 흰 글자 대비 약4.56:1을 확보했습니다. 사용자 확대/줄바꿈/reduced-motion/키보드 포커스/모달 focus trap을 지원합니다.

실제 렌더링한 로그인·대시보드·상세 주문·보유·분석·설정·연결 오류 PNG는 로컬 `.local/screenshots/`에 있습니다. 차트는 실제 원자료 계산을 렌더링하지만 데이터는 합성입니다.

## 아직 검증하지 못했거나 구현이 남은 범위

- 실제 KIS/SEC/뉴스·실적·경제지표·지수·업종·환율·마스터·거래정지/경보·기업행동 연결과 저장/실시간 권한.
- 실증권사 해외 주문·정정/취소·체결통보·계좌/외부 앱 거래 대사. 모의 복구 테스트를 실거래 대사 테스트로 해석하지 마세요. KISBroker의 실주문 capability는 false입니다.
- 실제 과거 장기/PIT/상장폐지/구성종목, 뉴스 결합 성과, 상관관계·동시 보유를 반영한 전체 포트폴리오 백테스트. 가격 엔진과 합성 실험만 검증했습니다.
- 실제 Render 계정·현재 원격 Blueprint 스키마와 플랜 요금·리전/출구 IP·HTTPS 로그인 및 재배포 검증. 현재 Render 파일은 로컬 구문/빌드만 확인했습니다.
- Windows 호스트 자체 실행과 실제 모바일 기기/보조공학 전반. Windows 절차 및 반응형 Chromium 렌더링은 제공했습니다.
- GitHub Actions 원격 실행, 환경 게시 및 새로운 cloud task에서의 복원. 코드/설정 저장을 해당 검증 완료로 표현하지 않습니다.

실제 라이선스와 요금이 필요한 데이터/운영 항목은 [DATA_SOURCES.md](DATA_SOURCES.md), [DEPLOY_RENDER.md](../DEPLOY_RENDER.md)에 기록했습니다. 미확인 현재 금액을 확정하지 않았습니다.

## 재사용 환경 저장

현재 인스턴스에서 웹/DB 건강 상태, 로그인 후 최신 워커 heartbeat, 초기 모의 계좌 $10,000 및 로그아웃 후 접근 거절을 확인했습니다. 테스트가 남긴 개발용 기록은 ignored 백업에 보존하고 초기 계좌로 정리했습니다. 임시 브라우저 테스트 비밀번호 파일은 삭제했으며 소유자는 자기 비밀번호 해시를 안전하게 설정한 뒤 웹을 재시작해야 합니다.

클라우드 환경 초안의 `install_script`와 `start_skill` 저장이 확인됐습니다. Node/Python 설치·빌드, 기존 체크아웃 사용(별도 worktree 생성 금지), PostgreSQL·마이그레이션·독립 웹/워커 시작, 준비 상태 확인 및 별도 테스트 DB 사용을 포함합니다. 저장은 실행/게시를 의미하지 않으며 환경 설정에서 검토·저장 후 환경을 게시해야 합니다. Render 배포와는 별개입니다.

## 무료 모드 추가 검증 (2026-10-18)

- PostgreSQL 단위/통합 테스트 **68개 통과**. 추가 범위: 동시 요청의 영속 한도, 재시작 후 예산 유지, 차단 캐시의 DB 조회 방지, 작업 한도 후 읽기 허용, 저장 한도, 수동 매수/부분 체결/분석/백테스트/매도, 오래된 시세 차단, 워커/WebSocket/실주문 거절, Neon Direct/TLS 설정 검사. testclient의 httpx 관련 deprecation 경고1개가 있다.
- 무료 브라우저 흐름1개 통과: 로그인 후 기존 폴링 주기보다 긴6.5초 동안 API 요청0회 및 WebSocket0개, 수동 부분/전량 체결, 분석, 매도,360/768/1440px 가로 넘침 없음. 첫 검증에서 발견한 초기 후보 버튼 잠김은 수정 후 재검증했다.
- 기존 워커 모드의 데스크톱·모바일 브라우저 흐름2개도 재검증하여 통과했다.
- Docker 새 이미지 빌드와 실제 런타임 검증 통과: 비루트 UID10001,512MiB 제한, PORT8080, 자동 마이그레이션, 비밀 파일 미포함, 로그인/추천, 수동3/5주 체결 후 컨테이너 재시작, 세션/예산/기록 복원, 나머지2주 중복 없이 체결, 요청 내 보유 분석. Worker 컨테이너를 만들지 않았다. 이 검증은 독립 *_test DB를 생성하고 종료 시 제거했다.
- 프런트 빌드·Ruff·Alembic schema diff·로컬 무료 설정 검사/DB 읽기 검사 통과. `render.yaml`은 공식 Blueprint 문서의 현재 `autoDeployTrigger: off`와 Docker/Free 필드를 사용하며, 로컬 YAML 구조 검증상 Free Web1개뿐이다.
- 공급자 API로 Blueprint 검증/리소스 생성·Neon 실제 TLS 접속·계정 Free 플랜/결제수단/지출 한도·실제 HTTPS 인수 검증은 **미실행**이다. Render API 키와 실제 Neon 연결값이 환경에 없다. 앱 예산은 공급자 실제 청구량의 계측/보증이 아니다.
